UT4 Recon - Input Paks
======================

Place the cooked .pak file you want to inspect or repair in this folder.

Dropping a file here does not modify or open it automatically. Keep the original
pak as a backup, then use the UT4 Recon command prompt or editor workflow to
create a recovery project from the file.

Setup also creates sibling folders for Recovery Projects and Built Paks. These
working folders and their contents are preserved if UT4 Recon is uninstalled.
